# Day-Ahead Demand Response Decision System

A day-ahead demand response (DR) decision pipeline for the German electricity market under price forecast uncertainty.

## Pipeline

```
forecast → scenario generation → DR optimization → counterfactual evaluation
```

| Stage | Script | Description |
|-------|--------|-------------|
| 1 | `run_01_prepare_data.py` | Load OPSD data, feature engineering (lags, energy-mix, holiday features) |
| 2 | `run_02_features_elasticity_dr.py` | Dynamic elasticity estimation, baseline demand, DR features |
| 3 | `run_03_forecast_calibration_scenarios.py` | RF forecast → linear calibration → block bootstrap scenarios (48 × 656h) |
| 4 | `run_04_day_ahead_decision.py` | Counterfactual price model + grid-search DR optimization |
| 5 | `run_05_counterfactuals.py` | Figures 1–4, 6 (calibration, scenarios, schedule, counterfactual, regime) |
| 6 | `run_06_evaluation_dashboard.py` | Four-level evaluation (L1 forecast / L2 scenario / L3 decision / L4 mechanism) |

Run all steps:
```bash
python scripts/run_all.py
```

## Key Results (Q4 2018, German market)

| Metric | Value |
|--------|-------|
| Forecast MAE (H=24) | 13.59 €/MWh |
| Total market cost reduction | €409.8M |
| Average price reduction | 5.65 €/MWh (−11.5%) |
| High-price hours reduced | 65 / 66 |
| Negative-price recall (classifier) | 23.8% |
| L4 mechanism checks passed | 8 / 8 |
